📘 设计说明 —— 这是静态 HTML 原型（点开看覆盖范围与未做到的部分）

🧪 这是什么

  • 静态原型：单文件自包含，CSS/JS 全内联，零外部 CDN / 字体 / 图片，断网双击可开。
  • 图标全部用 emoji + 纯 CSS；图表（柱状 / 环形）用 纯 CSS conic-gradient 与高度百分比 画，未引任何图表库。
  • PC 后台布局：左侧固定菜单 224px + 顶栏 54px + 内容区，按 1440px 宽设计（min-width:1440px）。
  • 12 屏单页切换，不是滚动长廊；每屏内容区顶部标注 屏号 + 页面名。
  • 数据为手写 realistic 假数据（昵称 / 任务标题 / 金额 / 时间 / 操作员 ID），不代表真实业务数据。
  • 页面运行时零网络请求（已用 Chrome DevTools 实测 performance 资源列表为空）。

🚧 没做到的部分（如实说明）

  • 无后端：所有"提交/通过/驳回"只出 toast 或弹层，不落库、不校验、刷新即还原。
  • 登录与鉴权是假的：岗位切换器直接改前端状态，没有 token、没有接口级 403 演示。
  • MFA 是假的：任意 6 位数字都能通过；不校验 TOTP，不区分设备。
  • 表格排序/筛选/分页仅前端：只对内置假数据有效，跨页排序按整表内存排序。
  • 图表是示意：数值手写，非实时聚合；无时间范围切换、无下钻。
  • 未独立成屏：UC-A-05 内部账号管理 / 07 组织与数据权限 / 09 任务分类管理 / 16 通知模板 / 20 系统公告 / 22 活动费率 —— 只在相关屏里留了入口或说明。
  • 未覆盖：文件上传、IM 记录只读调阅的真实会话窗口、导出功能、消息推送、暗色模式、无障碍（键盘可达性只做了基础）。
  • 数据未与 db/migration 对齐：参数键名取自 V4 种子数据，但界面数值为演示值，未跑 SQL 校验。
