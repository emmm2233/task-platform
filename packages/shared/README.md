# @task/shared（四端共用契约）

⭐ **存在的唯一理由**：三个前端 + 小程序都要用同一套接口契约。
手写两份必然漂移 —— 后端改了个字段名，前端要到运行时才发现。

## 现状与下一步

当前是**手写的类型**，与 `api/openapi.yaml` 对齐。
⚠️ **尚未做的**：从 OpenAPI 自动生成（`openapi-typescript`）。
在那之前，**改后端接口时必须同步改这里** —— 这是当前唯一的漂移风险点，
写在这里以免被忽略。

⛔ 不要在 `web-user` / `web-admin` / `apps/mobile` 里各写一份接口类型。
