## 阶段门（每阶段都必须过，不可跳过）

1. `mvn -pl platform-app -am test` → **全绿**，且读 surefire **总计行**（⛔ 不要自己加每个类的行数）
2. `node tools/check-consistency/check.mjs` → **0 违规**
3. `node tools/check-consistency/test/run.mjs` → **10/10**
4. 三端构建：`pnpm --filter web-user build` · `web-admin` · `mobile build:mp-weixin`
5. ⭐ **新增/修改的断言必须能失败**：故意把实现改坏，测试/脚本必须**红**。
   只证明"能通过"等于没验证 —— 本会话已三次证明"因为错误原因而通过"。
6. 涉及 HTTP / 安全配置的改动：⛔ **必须 `package` 后真实启动 + 打真实接口**，
   只跑 `mvn test` 用的是旧 jar。
7. 提交前跑门禁并**带守卫**：
   ```powershell
   & node tools/check-consistency/check.mjs
   if ($LASTEXITCODE -ne 0) { '门禁红，拒绝提交'; exit 1 }
   git commit ...
   ```
