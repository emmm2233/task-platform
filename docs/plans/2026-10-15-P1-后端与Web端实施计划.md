# P1 后端与 Web 端实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付「发单 → 抢单/竞拍 → 托管 → 交付验收 → 抽成分账」的完整闭环，Web 用户端与管理端可用，并为微信小程序与手机 App 预留全部接口能力。

**Architecture:** 模块化单体（9 个限界上下文）+ 独立 WebSocket 进程 `app-ws`；前端两个 Vue 3 工程 `web-user` / `web-admin` 共享 `packages/shared`（OpenAPI 生成的 TS 类型）。资金与抽成走**条件更新 + 双分录记账 + 渠道分账**，⛔ 不归集资金。

**Tech Stack:** JDK 21 · Spring Boot 3.2 · Spring Security 6 · MyBatis-Plus 3.5 · Spring StateMachine 3.2 · MySQL 8.0.36 · Redis 7.2 · RocketMQ 5.1 · XXL-Job 2.4 · MinIO · Vue 3.4 · TypeScript 5.4 · Vite 5 · Pinia · Element Plus 2.7 · pnpm 9

**Spec:** [`docs/2026-10-15-任务撮合平台-总体设计.md`](../2026-10-15-任务撮合平台-总体设计.md)（v1.6）—— 计划从规格论证，执行者**两份都要读**
**已有资产:** DDL `db/migration/V1–V6`（71 表，实跑通过）· OpenAPI `api/openapi.yaml`（108 路径）· WS 协议 `api/websocket-protocol.md` · 原型 `prototype/mp-weixin` `prototype/web-admin`

## Global Constraints

| # | 约束 | 值 |

| G15 | 二清红线 | ⛔ 平台自有账户不得归集他人资金；佣金**只能通过渠道分账指令**划取 |

| **RF4** | **支付回调重复与乱序**：同一回调推 3 次 · 退款回调先于支付回调到达 · 订单已取消后回调才到 | 重复 → 幂等返回成功、**不重复记账**；乱序 → 按状态机允许的迁移判定，非法迁移落异常单**不执行也不静默丢弃**；订单已取消 → 按退款处理并**告警** | **T18** |
| **RF5** | **信誉分恰好越界**：59→60（恢复接单权）· 39→40（出黑名单）· 100 封顶后继续加分 · 单日加分达上限 | 越界瞬间**等级与权益同步生效**（不是次日）；封顶后再加分**不报错**（静默截断并记 `raw_delta` 便于发现）；日上限截断同样不报错 | **T26** |
